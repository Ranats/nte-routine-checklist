NTE Routine Checklist Guide

NTE Routine Checklist is an unofficial fan-made checklist for players who want one place to track Neverness to Everness daily and weekly routines. It focuses on practical routine management: checking off completed tasks, hiding tasks that do not apply, adding custom tasks, and resetting progress by daily or weekly periods.

What the checklist is for

The app is designed as a browser-based personal tracker. The preset tasks are editable templates based on public routine guides, not an official source of game truth. If your in-game account, server, or event list differs, you can hide preset items and add your own checklist entries.

Daily and weekly routines

Daily tasks are intended for short-repeat actions such as stamina spending, daily guide rewards, login or event rewards, and other routine checks. Weekly tasks are intended for longer reset cycles such as weekly stamina, auction checks, weekly commissions, and other activities that do not need daily attention.

Completed items are shown with a checked state and dashed completion styling, so it is clear which tasks have already been handled in the current period.

Reset assumptions

The default Asia profile uses 05:00 server time. The app also includes America, Europe, and custom timezone settings. Regional conversions can differ by server and daylight saving, so treat the in-game timer as the final source when there is a mismatch.

Local storage and backups

Checklist state is stored in your browser. There is no account login, account linking, or app backend. You can export a JSON backup and import it later if you change browsers or want to keep a manual backup.
