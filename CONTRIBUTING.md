# Contributing

Contributions are welcome for checklist wording, translations, reset assumptions, accessibility, and small UI fixes.

## Local Setup

```powershell
npm install
npm run start -- --port 5174
```

## Checks

Run these before opening a pull request:

```powershell
npm run typecheck
npm test
npm run build
```

## Content Guidelines

- Keep the project clearly unofficial and fan-made.
- Do not add official logos, screenshots, character art, or game icons.
- Treat preset items as editable templates, not official game data.
- If a game update changes routines or timers, include the source and review date.
- Avoid adding analytics, tracking, or new third-party scripts without updating the privacy pages.
